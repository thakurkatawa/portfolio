# Thakur Katawa's Portfolio

A modern and minimal portfolio website built with **Next.js, React, TypeScript, and Tailwind CSS**.

This portfolio showcases my skills, projects, education, and experience as a **Computer Science Engineer and Full Stack Web Developer**.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/thakurkatawa/portfolio.git
```

### 2. Navigate to the project directory

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

### 5. Open the portfolio

Visit:

```text
http://localhost:3000
```

## 🔧 Customization

Portfolio content can be customized from the files inside the `data/` directory and the components inside the `components/` directory.

You can update:

* Personal information
* Projects
* Education
* Skills
* Social media links
* Images
* Portfolio sections
